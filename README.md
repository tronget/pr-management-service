# Сервис управления Pull Request'ами

REST-API сервис на Go для работы с пользователями, командами и pull request'ами. Хранение данных — PostgreSQL.

## Быстрый старт
По умолчанию команда `make` запускает цель `test-up`:
1. Поднимает контейнеры `db` (боевой `pr_db`).
2. Создаёт тестовую базу `pr_test_db` и применяет миграции.
3. Гоняет интеграционные тесты.
4. Если тесты прошли — стартует приложение на порту 8080.

Запуск:
```bash
make            # эквивалент make test-up
# или вручную без тестов:
docker compose up -d --build
```
Приложение: http://localhost:8080

## Цели Makefile
```text
make test-up      — миграции + интеграционные тесты + запуск приложения (дефолт)
make test-only    — миграции + интеграционные тесты (без приложения)
make migrate-test — только миграции для pr_test_db
make down         — остановить и удалить контейнеры
make help         — список целей
```

### Детали
- `migrate-test`: создаёт `pr_test_db` если её нет, применяет все `migrations/*.sql`.
- `test-only`: включает логику `migrate-test`, затем `go test` интеграционные.
- `test-up`: как `test-only`, но после успешных тестов запускает само приложение.
- `down`: останавливает и удаляет контейнеры (docker compose down -v).
